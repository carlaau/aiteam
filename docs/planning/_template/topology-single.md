- **worktree 隔离**：每位执行者用独立 git worktree+独立分支开发（`git worktree add`），同仓多会话并行靠目录隔离，不靠远端。
- **一任务一工作树**：一个执行者一个 worktree 一条分支，分支按批次/任务命名；多任务共用一条分支禁止——未提交改动会互相混入。
- **合并三步**：自测过后，①`git rebase master` 到最新（rebase 冲突由合并者解决）→ ②全量重跑（全部测试+静态检查零报错，不只跑本任务）→ ③`git merge --no-ff` 回 master。
- **合并序**：多人并行合并按任务档既定行序串行，见自己行以上全部「已合并」才走合并三步；git 写全局串行由行序制保证。
- **无远端口径**：本拓扑默认单机仓，禁止 push/建远端；主干推进仅靠本地 `merge --no-ff` 串行合并。
- **收尾清理**：任务合并回 master 后删除对应 worktree 与分支（`git worktree remove` + `git branch -d`），防目录堆积与幽灵分支。
