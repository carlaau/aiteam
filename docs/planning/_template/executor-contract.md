## 一、批次开发五步纪律链（每批必走全五步，顺序不可跳）

<!-- 此节写什么：S4 每批次的固定动作链——五步顺序不可跳、每步对应一个技能（`.agents/skills/`，init 默认安装）；引用技能名必须与该目录实际技能名逐字一致（断链自查项）。允许按项目裁剪的只有第 4 步的适用条件（是否含 Web 页）。 -->

1. **using-git-worktrees**——收开工令后建 worktree+分支 `feat/{{BRANCH_PREFIX}}<N>`（隔离开发；状态/信号回写一律操作主仓路径）。
2. **subagent-driven-development + test-driven-development**——先以 Skill 工具加载，严格按其流程：plan 每个实现任务 spawn 独立子代理执行（子代理内测试先行：红→绿→重构），主会话只做任务下发/结果审查/commit 收口；**主会话禁止直接写实现代码与测试**（例外封闭清单：交互式浏览器调试/用户在环/git 合并高危操作/哨兵与信号回写）。
3. **requesting-code-review 并自行修复**——全部开发任务完成后、合并前，先以 Skill 工具加载并按其流程**自审一轮**：对照 plan 任务清单/AC/工程规范逐项过，发现的问题**当场修复**（修复属「自测」的一部分，不留独立报告；自审通过是「自测过」的前提）。
4. **含 Web 页面的批次：浏览器自测并修复**——GUI 黑盒点走查核心动线，修完复测；纯后端/文档批跳过本步（在 plan 执行模式行声明）。
5. **finishing-a-development-branch**——以上全过才收尾：回主仓 rebase master → `merge --no-ff` 回 master → 删分支/worktree（**远端操作按 {{REMOTE_POLICY}}**）。

## 二、收尾与信号（两步落盘，缺一=断链）

<!-- 此节写什么：批次做完后的固定落盘序列——状态回写（操作主仓路径）+信号发出+重挂哨兵+醒后先读信号四动作；通讯纪律全部走 aiteam CLI（send/poll/ack/status/watch），不依赖任何会话记忆。 -->

1. 批次状态回写任务档 §4 批次表（置「已合并待审」）——操作**主仓路径**。
2. **向总控发信号**（aiteam CLI 语境：`{{PROJECT_BIN}} send` 定向总控角色，正文含「批次号 已合并待审——merge <hash>」）→ 写完顺手 commit。
3. 重挂哨兵值守总控信号：`{{PROJECT_BIN}} watch`（挂法=会话内后台任务 `&`，监控总控所在信箱——具体参数以 `{{PROJECT_BIN}} watch --help` 与接入指南为准）。
4. **醒来第一读**：哨兵唤醒→`{{PROJECT_BIN}} poll` 拉总控信箱未消费消息→按指针分流（初审通过/返工单/关批/下一批开工令）→干活，不凭记忆开工。

## 三、返工与时间盒

<!-- 此节写什么：返工的固定路径（master 上追加修复 commit→信号回报→等复验）与时间盒纪律（单批上限、到点动作、哨兵常挂口径）——「到点收尾写状态停下」必须写死，防无限磨。 -->

- 收返工单：在 master 上追加修复 commit（中文 message）→ 信号回报 → 等总控复验。
- 单批次时间盒 ≤{{TIMEBOX_HOURS}} 小时会话时间：到点未完=收尾写状态（任务档 §6 检查点+进度）停下汇报，不无限磨。
- 哨兵纯传呼机（不带 `--max-wait` 常挂，纪律同 .aiteam/onboarding.md「哨兵与值守纪律」节——init 渲染，项目内自包含）：无「值班到点退出」形态——时间盒到点收尾汇报后**照常重挂哨兵**等总控续作令（叫号制，不自查 git log）；流转停滞感知归 watchdog 巡检，不归哨兵超时。
- **哨兵常挂（消费端适配前置）**：干活中也挂——值守与工作并行，不因开工而摘哨；**挂法前提=命中有会反应的消费端**（宿主后台任务退出通知/人在终端/--on-hit 钩子），无消费端的分离式挂法（无人读的日志/nohup）=哑炮，禁用。

## 四、红线

<!-- 此节写什么：执行者身份的绝对禁区——禁产 spec/plan、开窗≠开工、远端操作按 {{REMOTE_POLICY}}、实现必须子代理、测试自造自清；红线是「违反即返工」级，不与「建议」混写。 -->

- 禁止产 spec/plan（恒由总控侧文档子代理产）；spec/plan 恒由总控侧按文档生产技能链产出（brainstorming/writing-plans/spec-review，以 Skill 工具加载）——执行者不产也不复述；开窗≠开工（唯一开工定义=收到总控开工令信号）。
- 远端操作（push/建远端）按 {{REMOTE_POLICY}}；git 操作纪律按工程规范对应节。
- 实现类任务必须子代理（封闭例外仅 §一第 2 步所列四条）；测试自造自清、不碰他人产物。
